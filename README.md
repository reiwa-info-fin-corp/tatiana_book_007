# まえがき
この問題集は、Node.js初心者から中級者を対象にした、Node.jsとネットワークの理解度を深めるための練習問題132問です。Node.jsを理解するためには、ネットワークの知識もある程度必要です。そのため、Node.jsとネットワークの両方の問題を用意しました。Node.jsとネットワークの基本的な概念をしっかりと理解し、スキルを向上させたい方にぴったりのコンテンツとなっています。一部、基本情報技術者試験の問題も含みます。  

## 主な対象者
Node.js初学者から中級者  
Node.jsと一緒にネットワークも学びたい方  
nvm (Node Version Manager) や npm (Node Package Manager) の基本的な使い方を学びたい方  
Node.jsのパッケージであるLuxon(ルクソン)とExpress(エクスプレス)を学びたい方  

## 本書の特徴
ネットワークの問題: Node.jsを勉強する上で必要となるネットワークの基礎問題を用意しました。  
Node.jsの問題: nvm (Node Version Manager) や npm (Node Package Manager) に関する問題、URL解析、http/httpsサーバーの設立方法の問題を用意しました。  
Node.jsのパッケージ  
Luxon(ルクソン):現地時間を取得し、日時の操作とフォーマットが可能なパッケージ。  
Express(エクスプレス):WebアプリケーションやAPIを構築するための高速でミニマルなフレームワークとして使われるパッケージ。  

## 学習の狙い
Node.jsとネットワークの両方を学び、バックエンド開発に必要な知識の理解を深める。  
プロのバックエンド開発者に一歩近づくためのスキルを習得する。
